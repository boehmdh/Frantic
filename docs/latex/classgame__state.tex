\doxysubsection{Detailed Description}
This is the main class comprising the current game state and functions for any game action.

As this class\textquotesingle{} field holds the game state, every player action involves invocation of one of the following methods. These comprise a check whether the respective action is valid and reject invalid requests. To facilitate serialization of attributes holding the game state, this class inherits from \doxylink{classunique__serializable}{unique\+\_\+serializable}.
