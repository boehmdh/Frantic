\{\#mainpage\} This is a simple C++ implementation of the game "{}\+Frantic"{} by RULE FACTORY. You can read the game\textquotesingle{}s rules \href{./docs/Regeln.pdf}{\texttt{here}}. Please note that not all event cards and action cards are implemented. The game is restricted to the event cards\+: "{}\+DOOMSDAY"{}, "{}\+EARTHQUAKE"{}, "{}\+FINISH\+\_\+\+LINE"{}, "{}\+TIME\+\_\+\+BOMB"{}, "{}\+COMMUNISM"{}, "{}\+EXPANSION"{}, "{}\+THIRD\+\_\+\+TIME\+\_\+\+LUCKY"{}, "{}\+MEXICAN\+\_\+\+STANDOFF"{}, "{}\+ROBIN\+\_\+\+HOOD"{}, "{}\+MATING\+\_\+\+SEASON"{}, "{}\+FRIDAY\+\_\+\+THE\+\_\+13\+TH"{}. The action cards in the game are\+: "{}\+NONE"{}, "{}\+SKIP"{}, "{}\+REVERSE"{}, "{}\+FANTASTIC\+\_\+\+FOUR"{}, "{}\+EQUALITY"{}, and "{}\+SECOND\+\_\+\+CHANCE"{}. "{}\+REVERSE"{} has the effect of changing the turn direction as opposed to exchanging cards and "{}\+SKIP"{} skips the next player; it is not possible to choose which player is skipped. The implementation features a client/server architecture for multiplayer scenarios. It uses \href{https://www.wxwidgets.org/}{\texttt{wx\+Widgets}} for the GUI, \href{https://github.com/fpagliughi/sockpp}{\texttt{sockpp}} for the network interface, \href{https://rapidjson.org/md_doc_tutorial.html}{\texttt{rapidjson}} for object serialization, and \href{https://github.com/google/googletest}{\texttt{googletest}} for the unit tests.
