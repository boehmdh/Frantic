Detailed Description

This is the main class comprising the current game state and functions for any game action.

As this class' field holds the game state, every player action involves invocation of one of the following methods. These comprise a check whether the respective action is valid and reject invalid requests. To facilitate serialization of attributes holding the game state, this class inherits from unique_serializable.

Returns true and draws a card if the player is allowed to do so.

This function checks whether the player is part of the game, it is his turn, the game has not finished and the player has already drawn a card in this turn. If one of these predicates apply the function returns false. Otherwise, by calling draw_card_action(player* player) a card is drawn and the function returns true.

◆ play_card()

bool game_state::play_card ( player * player,
const std::string & card_id,
uint new_wish,
uint ff_target,
std::string & err )

Returns true if the player could play the card, otherwise false.

Again, it is ensured the player is part of the game, it is his turn, the game has not finished yet and the Frantic rules allow the card to be played on the top card on the discard pile. If one of these conditions fail, the method returns false. Otherwise, the card is played and the respective effects are executed. If a black card is played, the top card of the event draw pile is played on the event discard pile and the respective effect takes place. If the player just played his final card, the round is wrapped up.

◆ wrap_up_round()

void game_state::wrap_up_round ( std::string & err)

Called upon termination of one round.

Upon the end of a round, increments the player's points according to their remaining hand. If one player exceeds the limit of 140 points after incrementing, end_game() is called and the game will be terminated immediately. Otherwise, the subsequent round will be set up.
