bool player::fold ( std::string & err)

Folds and returns true if permitted.

Checks whether the player is on turn and has already drawn a card. If both is true, the turn is passed to the next player. Otherwise no effect takes place and the method returns false.

◆ has_drawn()

bool player::has_drawn ( ) const
noexcept

Returns true if the player has already drawn in this round.

Is only set to true by a deliberately drawing a card, not if an effect or a 'Fantastic Four' card forces the player to draw. Only if the player has drawn a card, he is permitted to fold.
