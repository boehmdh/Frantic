uint MainGamePanel::ShowWishColorMessage ( )

Displays a dialog for the player to choose a color or number for a Rainbow card.

If a Rainbow card is on top of the discard pile, this function asks the player for a color or number for the wish. The choices for colors are Red, Blue, Green, and Yellow. The number choices range from I to IX.

Returns
uint The selected color (as Color enum) or number (1-9) chosen by the player.
